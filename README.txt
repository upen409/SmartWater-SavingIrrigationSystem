SMART WATER-SAVING IRRIGATION SYSTEM — WEBSITE PROTOTYPE

Files:
- index.html: the complete website (HTML, CSS, and JavaScript in one file).

How to run:
1. Download and extract the ZIP file.
2. Open index.html in Chrome, Edge, Firefox, or another modern browser.
3. Move the soil-moisture slider.
4. Press "Check watering recommendation".
5. Try "Try dry soil" and "Try wet soil".
6. Add test cases to the temporary test log.

Important:
This is a simulation, not a real sensor or automatic watering device. Record actual results from your own tests. The example threshold is adjustable and is not suitable for every plant. Do not claim that the prototype saves a measured amount of water unless you conduct a real comparison.
